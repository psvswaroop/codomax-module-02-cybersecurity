# Codomax Internship — Module 02
## Linux Security Tools & Reconnaissance

This repository documents the learning objectives and controlled lab methodology for Codomax Digital Solutions Internship Module 02 (Day 6–Day 10).

### Objectives
1. Learn Linux fundamentals: files, directories, permissions, users, groups, processes and basic security.
2. Understand passive and active reconnaissance, DNS/domain information gathering and network enumeration.
3. Understand essential security tools: Nmap, Wireshark, Burp Suite and OWASP ZAP.
4. Plan a controlled reconnaissance lab and document observations responsibly.

### Repository contents
- `docs/` — module notes and final report.
- `labs/` — guided practical procedures and analysis templates.
- `commands/` — consolidated command reference.

### Safety and accuracy
- Run scans only against systems you own or have explicit permission to test.
- The examples use localhost or a deliberately authorized training target.
- Any output explicitly labelled **Illustrative sample** is an example for learning; it is not evidence of execution on the author's computer.
- Replace observation templates with your own verified results before presenting them as completed practical work.
- Active web vulnerability scans can affect applications. Use an intentionally vulnerable local lab and obtain permission first.

### Tools covered
Linux terminal, Nmap, Wireshark, Burp Suite Community/Professional (features vary by edition), and OWASP ZAP.
