## 1. Overview
This module covers Linux security fundamentals, reconnaissance, network enumeration and the role of common cybersecurity tools. It also introduces a controlled lab workflow for observing and documenting security-relevant behaviour.

## 2. Topics studied
- Linux filesystem navigation, permissions, ownership, users, groups and processes.
- Passive and active reconnaissance and common DNS record types.
- Nmap port scanning and service detection concepts.
- Wireshark packet inspection, TCP handshake, SYN scan patterns, TCP streams and retransmissions.
- Burp Suite Proxy and Repeater.
- OWASP ZAP passive and active scanning.

## 3. Tool roles
| Tool | Main use |
|---|---|
| Nmap | Host, port and service discovery |
| Wireshark | Packet capture and network protocol analysis |
| Burp Suite | Intercepting and manually testing web requests |
| OWASP ZAP | Web application traffic analysis and security scanning |

## 4. Controlled lab methodology
1. Define an authorized target, such as localhost or a deliberately vulnerable local training application.
2. Record the test environment, date/time and scope.
3. Perform only the checks allowed by the scope.
4. Capture relevant output or packet evidence.
5. Record observations, limitations and potential security implications.
6. Validate findings before assigning severity or calling them vulnerabilities.

## 6. Conclusion
The module provides a foundation for understanding Linux access controls, reconnaissance methods, network traffic analysis and web security testing tools. Responsible testing, authorization, evidence collection and careful validation are essential parts of a security assessment.
